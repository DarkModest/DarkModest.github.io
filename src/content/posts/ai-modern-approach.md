# Ch1 - 绪论

## AI 的定义

AI 研究理性智能体。

**理性智能体**：对每个可能的**感知序列**，给定感知序列提供的证据和智能体所拥有的任何**先验知识**，选择使**性能度量期望值**最大化的动作。

**感知序列**：智能体每一步都会收到一个感知（percept）。从开机到现在所有感知按顺序排成的列表，就是感知序列。

> 感知序列由环境决定，不由主观控制，且条目数指数增长。因此表驱动智能体无法适用。
>
> 因此，需要紧凑的智能体程序实现定义在所有感知序列上的策略（"strategy" in Game, "policy" in Markov Decision Process）.

感知序列提供的证据 + 先验知识：理性永远条件于所掌握的信息。

**期望值**：AI的工程目标是“在信息不完备下期望最优”。理性选择应当最大化期望值，而不是尝试做到“全知”（预知所有结果）。

**性能度量**：对环境状态的历史序列的评分标准。

性能度量的设计原则：

 1. 度量**状态**而不是行为。应该对于在环境中真正想要实现的目标设计度量，否则会导致刷分问题。同时，也应当定义在序列中，而不是单时刻。经济学中的古德哈特定律、教育学中的坎贝尔定律都在其它领域体现了这个问题。

 2. 站在设计者的视角上设计度量，而不是智能体/受益方视角。

    > 三视角：设计者（designer/principal）、受益方（beneficiary/user）、被评估智能体（agent）。

## 设计智能体的第一步：指定任务环境（PEAS）

PEAS: Performance, Environment, Actuators(执行器), Sensors.

环境的七个维度：

| 维度         | 容易侧                                        | 困难侧                   |
| ------------ | --------------------------------------------- | ------------------------ |
| **可观测性** | 完全可观测                                    | 部分可观测               |
| 参与者       | 单智能体                                      | 多智能体                 |
| **确定性**   | 确定                                          | 随机                     |
| **时序**     | 回合式（episodic, 每个感知-动作片段相互独立） | 序贯（当前动作影响未来） |
| 变化         | 静态                                          | 动态                     |
| 取值         | 离散                                          | 连续                     |
| 知识         | 已知（规则我知道）                            | 未知                     |



# Ch2 - 智能体

智能体 = 架构 + 程序。

## 智能体程序

智能体程序的框架：传感器产生感知，输入程序；程序输出动作给执行器。

> 区分程序和函数。智能体程序的环境中没有其他可用信息，只能将当前感知作为输入；智能体函数可能依赖整个感知历史。如果智能体动作需要依赖整个感知序列，智能体必须记住历史感知。
>
> 表驱动的智能体构造方法必然失败，因为“记住历史感知”会导致条目数指数增长以至于无法存储。

人工智能面临的**关键挑战**是找出编写程序的方法，尽可能从一个小程序而非从一个大表中产生理性行为。

### **四级智能体程序**

1. 简单反射型 Simple Reflex
   - 只有条件—动作规则（if *percept_X* then *action_Y*），没有记忆。
   - 当环境完全可观测时，能够正常工作。部分可观测时失效（陷入循环）。
2. 基于模型的反射型 Model-Based Reflex
   - 在简单反射型上增加：
     1. 内部状态（记住世界当前状态）
     2. 转移模型（动作如何改变世界）+ 传感器模型（世界如何映射为感知）
   - 仍为反射式，但规则条件建立在内部维护的世界状态上。在不确定环境下变成一个严格的推断问题。
3. 基于目标的 Goal-Based
   - 模式：显式表示目标。决策分两步：1. 模拟世界变化（利用转移模型）2. 判断是否达成目标。过程被称为**搜索**。
   - 代价：慢；好处：灵活，换目标无需改程序，仅需修改目标描述。
4. 基于效用的 Utility-Based
   - 把“达成/没达成目标”升级成效用函数，决策升级为“选期望效用最大的动作”。
   - 效用函数能在多个目标冲突时权衡更多条件。

### **三级表示**

1. 原子表示 Atomic

   - 状态为黑盒，没有任何可见的内部结构，如BFS等搜索算法、MDP、HMM。
2. 因子化表示 Factored
   - 将状态拆分为一组固定的变量和属性。每个变量和属性都可以有一个值。
   - 两个不同的因子化状态可以共享某些属性而其他属性不同，使研究状态转换变得更加容易。
   - 能够表达部分知识、利用变量间的独立性、跨状态泛化。
   - 如 CSP、PDDL 规划、贝叶斯网络。

3.  结构化表示 Structured
   - 状态里不再是平级变量，而是对象、对象的属性、对象之间的关系。
   - 极大提高了表达力，但代价是推理复杂度激增、不一定可判定。
   - 如一阶逻辑与知识表示、自然语言。

> Tips:
>
> 1. 好的表示让“对推理有用的结构”变得可见。
> 2. 深度学习本质动作之一是“表示的自动升级”，如神经网络逐层将原始信息越来越结构化。
